## Автентифікація та доступ (Laravel Breeze)
- Реєстрація, вхід, вихід, відновлення пароля: `/register`, `/login`, `/forgot-password`.
- Публічні маршрути: головна, перегляд ігор, блогу, платформ і країн, контакти.
- Захищені (middleware `auth`): керування іграми (`/games/admin`, створення, редагування, видалення, переклади), адмінка блогу, мітки, статистика, `/users`, `/dashboard`, `/profile`.
- Меню залежить від стану входу (`@auth` / `@guest`); у кабінеті `/dashboard` відображаються ігри поточного користувача.
- Інтерфейс Breeze українською: `lang/uk.json`, `lang/uk/*.php`.
- Стилі Breeze зібрані окремо (`resources/css/breeze.css`), щоб не змінювати вигляд решти сторінок. Після `npm install` виконайте `npm run build`.
