## Пошук, фільтрація та сортування (адмінка)
- `/blog/admin` та `/games/admin`: пошук, випадаючі списки, сортування за пов'язаними даними.
- Логіка запитів винесена в `app/Queries` (`BlogFilter`, `GameFilter`); сортування лише за білим списком колонок.
- Пов'язані дані завантажуються через `with()`, кількість зв'язків: `withCount()`.
- Параметри `title`, `developer`, `platformName`, `platform_id`, `sort` зберігаються під час пагінації.
